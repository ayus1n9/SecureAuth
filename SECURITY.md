# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting a Vulnerability

The SecureAuth team takes the security of our application seriously. If you believe you have discovered a security vulnerability in this project, please report it responsibly:

1. **Do not create a public GitHub issue** disclosing the vulnerability.
2. Email the maintainer directly at `security@secureauth.local` with details:
   - Type of vulnerability (e.g. Broken Access Control, CSRF, Injection).
   - Step-by-step reproduction instructions or proof-of-concept payload.
   - Potential impact and suggested remediation.
3. You will receive an acknowledgment within 48 hours.
4. We kindly ask you to maintain responsible disclosure until a patch has been published.
